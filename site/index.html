Unnotarized release — Ad-hoc signed, not Apple-notarized. Manual macOS approval required. No Homebrew install.

First launch & permissions

Open the DMG, read the included first-launch guide, and drag Toolbox to Applications. Try opening once; if macOS blocks it, use System Settings → Privacy & Security → Open Anyway. Optional Full Disk Access expands readable coverage. Protected locations may remain inaccessible.
