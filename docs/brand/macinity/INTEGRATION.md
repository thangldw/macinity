# Macinity integration

## English

Cobalt Link is the current identity: app icon, sidebar/About mark, menu template, permission copy and four-language branding. Reproducible assets and palette are in [BRAND-GUIDE.md](BRAND-GUIDE.md).

Bundle ID `com.thang.toolbox`, executable/modules, preference keys and `Application Support/Toolbox` remain stable. Internal OrvenTheme names are compatibility details. Macinity 3.1.0 replaces current-facing Orven branding; old GitHub release assets remain immutable.

Prior native checks covered the sidebar, About, Japanese/Chinese Settings and menu toggling. Final-version GUI and Dock/status-glyph checks are not inferred from those observations. See [release readiness](../../production/RELEASE-READINESS.md). Private screenshots remain outside the public repository.

## Tiếng Việt

Cobalt Link là nhận diện hiện tại: icon app, logo sidebar/About, template menu, giải thích quyền và nội dung bốn ngôn ngữ. Asset tái tạo được và bảng màu nằm trong [BRAND-GUIDE.md](BRAND-GUIDE.md).

Giữ bundle ID `com.thang.toolbox`, executable/module, khóa cấu hình và `Application Support/Toolbox`. OrvenTheme là tên nội bộ để tương thích. Macinity 3.1.0 thay nội dung Orven hiện hành; giữ nguyên asset GitHub release cũ.

Kiểm tra native trước đây bao phủ sidebar, About, Settings Nhật/Trung và bật tắt menu. Không suy ra kiểm chứng GUI phiên bản cuối hay hình Dock/status từ các lần đó. Xem [release readiness](../../production/RELEASE-READINESS.md). Ảnh riêng tư nằm ngoài repo công khai.
