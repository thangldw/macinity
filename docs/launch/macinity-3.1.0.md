# Macinity 3.1.0

## English

Macinity 3.1.0 introduces the Cobalt Link identity and expands Orven into a native Mac workspace. Developed by [thangldw](https://thangldw.github.io/) & Codex.

- Action Center collects favorites and recent workflows; Smart Diagnostics explains observed CPU, memory, storage and network conditions. Work Profiles preview selected workspace, audio and Keep Awake actions.
- Utilities cover startup/background inventory, Keep Awake, external drives/file locks, ports, batch rename with preview/undo, SHA-256, folder comparison, package/runtime inspection and device/workspace management.
- Battery details and charge/discharge history, clearer sensor groups, independent Disk and Network screens, automatic application inventory and Wi-Fi access tools extend monitoring.
- English, Vietnamese, Japanese and Simplified Chinese; language and appearance live in Settings.

Download the universal DMG and matching SHA-256 from this release. Requires macOS 13+. **Ad-hoc signed, not notarized**: after a blocked first launch, use **System Settings → Privacy & Security → Open Anyway**. Never disable Gatekeeper. Quit older Toolbox/Orven copies before installing Macinity.app; keep only the version you intend to launch. The bundle ID and Toolbox data directory remain compatible.

Current GUI performance, full VoiceOver, physical Intel/macOS 13, active Ethernet, real package/service/eject mutations and Accessibility window restoration are not fully verified. Sensor availability depends on hardware. No fan control, hard CPU caps, firewall, password extraction or privileged repair is provided. See [release readiness](../production/RELEASE-READINESS.md) and [utility boundaries](../product/SUPER-APP-EXPANSION.md).

## Tiếng Việt

Macinity 3.1.0 giới thiệu nhận diện Cobalt Link và mở rộng Orven thành không gian quản lý Mac native. Phát triển bởi [thangldw](https://thangldw.github.io/) & Codex.

- Action Center gom mục yêu thích và thao tác gần đây; Smart Diagnostics giải thích trạng thái CPU, bộ nhớ, dung lượng và mạng quan sát được. Work Profiles cho xem trước thao tác workspace, âm thanh và Keep Awake.
- Tiện ích gồm startup/background, Keep Awake, ổ ngoài/file đang mở, cổng, đổi tên hàng loạt có preview/hoàn tác, SHA-256, so sánh thư mục, package/runtime và quản lý thiết bị/workspace.
- Bổ sung thông tin pin/lịch sử sạc xả, nhóm cảm biến dễ đọc, tách Disk/Network, tự quét ứng dụng và tiện ích Wi-Fi.
- Hỗ trợ Anh, Việt, Nhật và Trung giản thể; ngôn ngữ/giao diện nằm trong Settings.

Tải DMG universal và SHA-256 cùng phiên bản. Yêu cầu macOS 13+. **Ký ad-hoc, chưa notarized**: nếu lần mở đầu bị chặn, dùng **System Settings → Privacy & Security → Open Anyway**. Không tắt Gatekeeper. Thoát Toolbox/Orven trước khi cài Macinity.app; chỉ giữ bản muốn sử dụng. Bundle ID và thư mục dữ liệu Toolbox vẫn tương thích.

Hiệu năng GUI hiện tại, VoiceOver đầy đủ, Intel/macOS 13 thật, Ethernet hoạt động, thao tác package/dịch vụ/tháo ổ thật và khôi phục cửa sổ qua Accessibility chưa được kiểm chứng đầy đủ. Sensor phụ thuộc máy. Không có điều khiển quạt, hard CPU cap, firewall, lấy mật khẩu hoặc sửa hệ thống đặc quyền. Xem [release readiness](../production/RELEASE-READINESS.md) và [giới hạn tiện ích](../product/SUPER-APP-EXPANSION.md).

## 日本語

Macinity 3.1.0はCobalt Linkのブランドを導入し、OrvenをMac管理用のnative workspaceへ拡張します。[thangldw](https://thangldw.github.io/) & Codexが開発しました。

- Action Centerはお気に入りと最近の操作、Smart DiagnosticsはCPU・メモリ・容量・ネットワークの観測結果を表示します。Work Profilesはworkspace・音声・Keep Awake操作を事前確認します。
- 起動項目、Keep Awake、外部ドライブとファイルロック、ポート、一括名称変更と取り消し、SHA-256、フォルダ比較、package/runtime、デバイスとworkspace管理を追加しました。
- バッテリー詳細と充放電履歴、整理したセンサー、独立したDisk/Network画面、アプリの自動一覧、Wi-Fiツールを提供します。
- 英語・ベトナム語・日本語・簡体字に対応し、言語と外観はSettingsで変更できます。

Universal DMGと対応するSHA-256を取得してください。macOS 13以降が必要です。**Ad-hoc署名、未notarized**です。初回起動が拒否された場合は **System Settings → Privacy & Security → Open Anyway** を使用し、Gatekeeperは無効にしないでください。旧Toolbox/Orvenを終了してからMacinity.appをインストールしてください。bundle IDとToolboxの保存先は維持します。

現行GUI性能、完全なVoiceOver、Intel/macOS 13実機、Ethernet、実際のpackage/service/取り出し操作、Accessibilityによる配置復元は十分に検証されていません。センサーは機種依存です。ファン制御、hard CPU cap、firewall、パスワード取得、特権修復は提供しません。[公開条件](../production/RELEASE-READINESS.md)と[ツールの制限](../product/SUPER-APP-EXPANSION.md)をご確認ください。
