Orven architecture and safety boundaries

English

Content
The supported route starts with foreground GUI input. The app shell coordinates ToolboxCore, ToolboxMonitoring, ToolboxStorage, and ToolboxChanges; Storage and Changes depend on Core. Core writes local audit records, and the feature modules call macOS services. GitHub Releases is contacted by the explicit update check; bounded Wi-Fi/LAN probes contact user-selected destinations. Monitoring shares one lifecycle-aware coordinator and bounded optional history.
Exclusions
The figure does not imply a privileged helper, automatic upload, automatic update installation, cloud storage, or a complete historical audit from FSEvents.
Safety boundary
Unreviewed mutation and automatic upload stop before their trust boundaries. The privileged moment shown is the foreground review plus immediate canonical-path revalidation; it is not elevated process privilege.

Tiếng Việt

Nội dung
Luồng được hỗ trợ bắt đầu từ input GUI ở foreground. App shell điều phối ToolboxCore, ToolboxMonitoring, ToolboxStorage và ToolboxChanges; Storage cùng Changes phụ thuộc Core. Core ghi audit record local, còn các feature module gọi service của macOS. GitHub Releases dùng check update explicit; Wi-Fi/LAN probes bounded kết nối đích người dùng chọn. Monitoring dùng một coordinator theo lifecycle và history bounded tùy chọn.
Không bao gồm
Sơ đồ không ngụ ý privileged helper, upload tự động, tự cài update, cloud storage hoặc historical audit đầy đủ từ FSEvents.
Ranh giới an toàn
Mutation chưa review và upload tự động dừng trước trust boundary. Privileged moment trong hình là foreground review cộng với canonical-path revalidation ngay trước action, không phải quyền process nâng cao.

日本語

内容
サポート対象の経路は foreground GUI input から始まります。App shell が ToolboxCore、ToolboxMonitoring、ToolboxStorage、ToolboxChanges を調整し、Storage と Changes は Core に依存します。Core は local audit record を保存し、feature module は macOS service を呼び出します。GitHub Releasesは明示update check、bounded Wi-Fi/LAN probeは選択destinationへ接続。Monitoringは単一lifecycle coordinatorと任意boundedhistory。
対象外
この図は privileged helper、自動 upload、自動 update install、cloud storage、または FSEvents による完全な historical audit を示しません。
Safety boundary
Review されていない mutation と自動 upload は trust boundary の手前で停止します。図の privileged moment は foreground review と action 直前の canonical-path revalidation であり、process privilege の昇格ではありません。
