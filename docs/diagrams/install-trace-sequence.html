Install Trace sequence

English

Content
The user selects a supported installer and the GUI calls coordinator.start. The coordinator captures a before snapshot and starts bounded FSEvents; after start returns, the GUI invokes NSWorkspace.shared.open(metadata.sourceURL) for normal macOS handling. Finishing captures after evidence, compares it, and persists the session and audit records.
Exclusions
Orven does not mount, execute, install, uninstall, or bypass Gatekeeper for the selected item. The sequence does not claim that FSEvents is a complete historical audit.
Safety boundary
The user starts and finishes the trace in the foreground. cancel() stops the journal and clears active-snapshot.json plus active-trace-metadata.json, so cancellation is not resumable. Only unexpected interruption may retain resumable metadata; resumed observation reports the interruption interval as reduced coverage.

Trace の開始と終了は user の foreground action です。cancel() は journal を停止し active-snapshot.json と active-trace-metadata.json を消去するため、cancellation は resume できません。Unexpected interruption だけが resumable metadata を保持でき、resume 後の observation は interruption 区間を reduced coverage として報告します。
