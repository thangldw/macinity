# Orven expanded workflows

## English

### Scope

Explain My Mac uses canonical evidence rules; Storage Growth compares bounded allocation checkpoints; Developer Workspace summarizes selected-root rebuildable artifacts; App Activity Timeline retains bounded session observations. Local Diagnostics previews exports. Hidden Space/Snapshots explains filesystem accounting with unknown categories explicit. Network Inspector reads observable verified socket identities; manual process priority lowering revalidates PID/start identity.

### Coverage and limits

No exclusive APFS snapshot-byte accounting, automatic cleanup, automatic process suspension/hard CPU cap, NetworkExtension firewall or complete network history is implemented. Existing eligible storage mutations and explicit developer commands retain their review/restore or irreversible-command boundaries.

### Verification

Features are implemented within the existing owners; documentation and release notes must describe their actual observational/manual scope, not parity with another product.
